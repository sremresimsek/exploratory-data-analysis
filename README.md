# Exploratory Data Analysis

**Guided EDA coursework & practical notebooks** · Python · pandas · NumPy · Matplotlib · Seaborn

This repository collects the exploratory data analysis exercises I practiced while learning to understand tabular datasets, investigate distributions and identify relationships between variables.

**Scope and ownership:** These are guided learning exercises, not independent research projects.

## Study notebooks

| Study | Focus |
| --- | --- |
| [MPG](mpg/mpg_analysis.ipynb) | Missing values, distributions, outliers, correlations and feature relationships |
| [Wine Quality](wine_quality/wine_quality_analysis.ipynb) | Distributions, correlations and red/white wine comparisons |

## Getting started

1. Create and activate a Python virtual environment.
2. Install dependencies: `python -m pip install -r requirements.txt`.
3. Open Jupyter: `python -m jupyter notebook`.
4. Run each notebook from its own directory with the corresponding CSV.

## Data and reproducibility

The notebooks were run locally during the cleanup using Python 3.12. Dependency versions are not locked, and the analyses are intended for learning rather than validated research. See [DATA_SOURCES.md](DATA_SOURCES.md) for dataset information.
